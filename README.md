# Titanic Classification - CodeAlpha Task 1

This project is part of the CodeAlpha Data Science Internship. The objective is to build a machine learning model to predict passenger survival on the Titanic dataset.

## 📊 Dataset

The dataset includes features such as:

- Passenger Class
- Sex
- Age
- Fare
- Embarked Port

## 🧠 Model

A Logistic Regression model was trained to predict survival outcomes.

## 📈 Results

- Model Accuracy: 85%
- Confusion Matrix and other metrics are included in the notebook.

## 📁 Files

- `titanic_classification_codealpha.ipynb`: Jupyter Notebook containing data preprocessing, model training, and evaluation.
